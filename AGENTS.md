# Правила работы

1. Экономить токены и контекст; не перечитывать весь repository без необходимости.
2. Перед задачей изучать только необходимые части проекта и проверять реальные связи файлов.
3. Текущий код — источник истины о фактически реализованном состоянии сайта.
4. Не редизайнить утверждённые части сайта без прямой команды.
5. Не менять контент без прямой необходимости. Дополнительные факты и ограничения — в `CONTENT.md`.
6. Не придумывать цифры, факты, опыт, результаты и проекты.
7. Не устанавливать новые dependencies без реальной необходимости.
8. После экспериментов удалять мёртвый код, лишние assets и dependencies; перед удалением проверять использование.
9. Учитывать обе языковые версии RU/EN в изменениях контента и UI.
10. После технических изменений запускать необходимые проверки, обязательно `npm run lint` и `npm run build`.
11. Не переходить к следующему этапу проекта без прямой команды.
12. Итоговые отчёты писать коротко и по делу.
