# 03_Design_Direction.md (v1)

# Цель документа

Определить единые правила визуального языка сайта, чтобы дизайн был
последовательным, современным и помогал достигать главной цели ---
получения приглашения на интервью.

------------------------------------------------------------------------

# Общий характер дизайна

Сайт должен ощущаться как:

-   современный цифровой продукт;
-   дорогой;
-   аккуратный;
-   профессиональный;
-   спокойный.

Визуальная подача должна усиливать содержание, а не конкурировать с ним.

------------------------------------------------------------------------

# Ключевые принципы

1.  Простота важнее оригинальности.
2.  Читаемость важнее эффектов.
3.  Контент всегда главный.
4.  Каждая анимация должна помогать восприятию.
5.  Любое визуальное решение должно иметь цель.

------------------------------------------------------------------------

# Визуальные ассоциации

Желаемое ощущение:

-   Premium Tech
-   Product Design
-   Editorial
-   Minimalism с характером

Не должно быть ощущения:

-   шаблонного лендинга;
-   креативного агентства;
-   портфолио дизайнера;
-   стартап-питча.

------------------------------------------------------------------------

# Цветовая система

Основа:

-   светлый фон;
-   один акцентный цвет;
-   нейтральная палитра;
-   мягкие тени;
-   чистые поверхности.

Акцентный цвет определяется после фотосессии и финального визуального
стиля.

------------------------------------------------------------------------

# Типографика

Приоритет:

1.  крупные заголовки;
2.  свободное пространство;
3.  комфортная длина строки;
4.  высокая читаемость.

Типографика должна создавать ощущение уверенности, а не декоративности.

------------------------------------------------------------------------

# Карточки

Все основные блоки оформляются карточками.

Требования:

-   большие внутренние отступы;
-   крупные радиусы;
-   аккуратные тени;
-   легкая глубина;
-   отсутствие визуального шума.

------------------------------------------------------------------------

# Анимации

Анимации должны быть плавными и спокойными.

Допустимо:

-   плавное появление;
-   fade;
-   slide;
-   небольшие смещения;
-   мягкий parallax;
-   микроанимации при наведении.

Недопустимо:

-   резкие вылеты;
-   сложные 3D-эффекты;
-   постоянные вращения;
-   отвлекающие анимации.

------------------------------------------------------------------------

# Hero

Первый экран обязан за 10 секунд ответить на вопросы:

-   Кто это?
-   На какую роль претендует?
-   Почему стоит продолжить просмотр?

На Hero должны быть:

-   имя;
-   должность;
-   краткое позиционирование;
-   опыт;
-   фотография;
-   основные CTA.

------------------------------------------------------------------------

# Кейсы

Каждый кейс оформляется как отдельный продукт.

Структура:

1.  Контекст.
2.  Проблема.
3.  Моя роль.
4.  Решение.
5.  Результат.
6.  Что я поняла.

Каждый кейс должен выглядеть как полноценное исследование.

------------------------------------------------------------------------

# Использование пространства

Не экономить вертикальное пространство.

Воздух --- часть дизайна.

------------------------------------------------------------------------

# Что запрещено

-   чрезмерные градиенты;
-   кислотные цвета;
-   стеклянные эффекты ради эффекта;
-   длинные стены текста;
-   карусели;
-   автопрокрутка;
-   перегруженные иллюстрации.

------------------------------------------------------------------------

# Адаптивность

Мобильная версия проектируется одновременно с десктопной.

Не допускается потеря смысла, структуры или качества взаимодействия.

------------------------------------------------------------------------

# Финальный критерий

Если убрать все анимации, сайт должен оставаться сильным.

Если убрать тексты, дизайн не должен пытаться заменить смысл.

Сильный сайт достигается сочетанием структуры, содержания и аккуратного
визуального исполнения.
